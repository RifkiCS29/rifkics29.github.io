Kebijakan Privasi

Kebijakan ini menjelaskan bagaimana PosOff mengelola data Anda. PosOff dirancang untuk beroperasi sepenuhnya offline, dan data Anda tetap berada di perangkat Anda.

Terakhir Diperbarui

10 Juni 2025

Pengumpulan Data

PosOff hanya mengumpulkan data yang Anda masukkan langsung ke dalam aplikasi, termasuk: informasi toko (nama, alamat, nomor telepon, logo, gambar QRIS), data produk (nama, kategori, harga, stok, gambar, barcode, SKU), data transaksi (item, jumlah, harga, metode pembayaran, tanggal), informasi staf (nama, email, peran, kata sandi), serta pengaturan aplikasi (bahasa, tema).

Penyimpanan Data

Semua data disimpan secara lokal pada perangkat Anda menggunakan database SQLite. Tidak ada data yang dikirim ke server eksternal atau cloud. Data hanya dapat diakses melalui aplikasi di perangkat yang sama tempat data tersebut dibuat. Fitur cadangan (backup) memungkinkan Anda mengekspor data ke file JSON yang disimpan di perangkat Anda.

Penggunaan Data

Data yang Anda masukkan digunakan secara eksklusif untuk menjalankan fungsi aplikasi POS, termasuk: memproses transaksi penjualan, mengelola inventaris produk, menghasilkan laporan penjualan, mencetak struk melalui printer Bluetooth, dan mengelola akses staf. Data tidak digunakan untuk analitik, iklan, atau tujuan lainnya.

Pembagian Data

PosOff tidak membagikan data Anda kepada pihak ketiga mana pun. Karena aplikasi beroperasi sepenuhnya offline, tidak ada mekanisme untuk mengirim data ke luar perangkat Anda. Satu-satunya cara data keluar dari perangkat adalah melalui fitur cadangan manual yang Anda inisiasi sendiri.

Keamanan Data

Keamanan data Anda bergantung pada keamanan fisik perangkat Anda. Kata sandi staf dienkripsi sebelum disimpan. Kami menyarankan untuk: mengunci perangkat Anda dengan PIN/sandi/biometrik, tidak membagikan akses perangkat kepada orang yang tidak berwenang, dan menggunakan fitur cadangan secara berkala untuk mencegah kehilangan data.

Hak Pengguna

Anda memiliki kendali penuh atas data Anda, termasuk: mengakses, mengedit, atau menghapus data kapan saja melalui aplikasi, membuat cadangan data dalam format JSON, memulihkan data dari file cadangan, dan menghapus seluruh data dengan menghapus aplikasi. Tidak ada proses akun atau langganan, sehingga Anda bebas menggunakan aplikasi sesuai kebutuhan.

Privasi Anak

PosOff bukan aplikasi yang ditujukan untuk anak-anak. Aplikasi ini dirancang untuk digunakan oleh pemilik usaha dan staf yang bertanggung jawab atas pengelolaan toko. Kami tidak secara sengaja mengumpulkan data dari anak-anak.

Perubahan Kebijakan

Kami dapat memperbarui kebijakan privasi ini dari waktu ke waktu. Perubahan akan tercermin dalam pembaruan aplikasi. Kami menyarankan Anda untuk meninjau kebijakan ini secara berkala, terutama setelah memperbarui aplikasi ke versi terbaru.

Privacy Policy

This policy explains how PosOff handles your data. PosOff is designed to operate entirely offline, and your data remains on your device.

Last Updated

June 10, 2025

Data Collection

PosOff only collects data that you directly enter into the application, including: store information (name, address, phone number, logo, QRIS image), product data (name, category, price, stock, images, barcode, SKU), transaction data (items, quantities, prices, payment method, date), staff information (name, email, role, password), and application settings (language, theme).

Data Storage

All data is stored locally on your device using a SQLite database. No data is sent to external servers or the cloud. Data can only be accessed through the application on the same device where it was created. The backup feature allows you to export data to a JSON file stored on your device.

Data Usage

The data you enter is used exclusively to run POS application functions, including: processing sales transactions, managing product inventory, generating sales reports, printing receipts via Bluetooth printers, and managing staff access. Data is not used for analytics, advertising, or any other purposes.

Data Sharing

PosOff does not share your data with any third parties. Because the application operates entirely offline, there is no mechanism to send data outside your device. The only way data leaves your device is through the manual backup feature that you initiate yourself.

Data Security

The security of your data depends on the physical security of your device. Staff passwords are encrypted before being stored. We recommend: locking your device with PIN/password/biometrics, not sharing device access with unauthorized persons, and using the backup feature regularly to prevent data loss.

User Rights

You have full control over your data, including: accessing, editing, or deleting data at any time through the application, creating data backups in JSON format, restoring data from backup files, and deleting all data by uninstalling the application. There are no account or subscription processes, so you are free to use the application as needed.

Children's Privacy

PosOff is not an application intended for children. This application is designed for use by business owners and staff responsible for store management. We do not knowingly collect data from children.

Policy Changes

We may update this privacy policy from time to time. Changes will be reflected in application updates. We recommend that you review this policy periodically, especially after updating the application to the latest version.
